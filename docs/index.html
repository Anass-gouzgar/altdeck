Engineered for Performance

Why AltDeck is Built Different

A lean, native Windows architecture designed to avoid proprietary hardware lock-in.

⚡

Sub-10ms Native C# Engine

Direct integration into low-level Windows APIs via a high-performance compiled companion (pc-control.exe). Taps directly into IAudioEndpointVolume CoreAudio COM interfaces, WMI physical monitor brightness, and SendInput hardware scancodes.

IAudioEndpointVolume WMI Brightness SendInput ScanCodes Windows COM
📐

Zero-Void Layout

Mathematically balanced multi-column grid with 0 empty slots across iPad Pro, Android tablets, smartphones, split-screens, and 4K ultrawide displays.

📊

Task Manager Deck

Real-time 60-second SVG load waveforms for CPU & RAM. Active scanner displaying the top 5 memory-heavy background apps with one-tap instant Kill buttons.

🚀

16-App Launchpad

Official high-resolution branding for VS Code, Discord, Claude AI, Chrome, Edge, Antigravity, Office 365, plus auto-scanner detecting installed PC software.

🌍

Trilingual & RTL First

Full dynamic localization in English, French, and Arabic with native RTL layout and Cairo typography. Plus 14 luxury dark themes for any setup.

☕

Universal 24/7 Keep-Awake Engine

Browser-based wake lock APIs normally require HTTPS, which breaks on local Wi-Fi IP addresses. AltDeck solves this with a dual-pipeline engine combining the Native Screen WakeLock API with an invisible seamless video buffer fallback (NoSleep.js), keeping your tablet awake indefinitely.

Quick Start

Up and Running in 60 Seconds

No external compilers, no manual dependencies, no cloud registration required. 

# 1. Clone the repository
git clone https://github.com/Anass-gouzgar/altdeck.git
cd altdeck

# 2. Install dependencies (Node.js 16+)
npm install

# 3. Start AltDeck
npm start
1
Run on PC
Double click start-controller.bat or run npm start. AltDeck auto-compiles the C# binary on first launch.
2
Open on Tablet
Open Chrome or Safari on your tablet and type the local IP address shown in terminal.
3
Add to Home Screen
Tap Install or Add to Home Screen for a borderless, full-screen deck experience.
